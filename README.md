# ANALIZA PRZESTĘPCZOŚCI LOS ANGELES

Projekt wykonany na platformie DataCamp, na podstawie danych udostępnionych przez LAPD. Celem projektu była indentyfikacja kluczówych trendów czasowych, lokalizacji największego ryzyka i analiza demograficzna ofria.

## Kluczowe zadania
- analiza czasowa; wyodrębnienie godziny w której dochodzi do największej ilości przestępstw.
- Identyfikacja obszarów zagrożenia przestępczego.
- Profilowanie ofiar według różnych grup wiekowych.

## Wykorzystane technologie
- Python (Pandas, NumPy) - obróbka danych
- Matplotlib, Seaborn - wizualizacja

## Wnioski
- godzina 12 jest szczytem przestępczości
- "Central" jest najniebezpieczniejszą dzielnicą Los Angeles
- osoby w wieku między 26-34 odpowiadają za największą liczbę wykroczeń
